# CHEESA Editorial Pick

Plugin blok OJS buatan sendiri untuk jurnal CHEESA (tanpa lisensi).
Menampilkan artikel pilihan editor sebagai:
- blok sidebar (aktifkan bloknya di Settings > Website > Appearance > Setup > Sidebar), dan
- (opsional) baris kartu ber-cover di beranda.

Kelola pilihan: Settings > Website > Plugins > CHEESA Editorial Pick > Kelola Pilihan,
atau buka /index.php/<jurnal>/editorialpick. Khusus Site Admin / Journal Manager / Editor.
