# Crossmark Button (OJS 3.3)

Tombol Crossmark "Check for updates" memakai widget resmi Crossref v2.

- Muncul hanya pada artikel yang memiliki DOI.
- Menambahkan `<meta name="dc.identifier" content="doi:...">` yang dibutuhkan widget.
- Pengaturan: bentuk logo, posisi (dekat judul / area isi), tanggal terbit minimal.
- Dengan CHEESA Theme, tombol otomatis ditempatkan di kepala artikel (kanan atas).

Syarat: jurnal terdaftar layanan Crossmark di Crossref dan metadata Crossmark ikut dideposit.
Pasang: Upload A New Plugin → `crossmarkButton-1.0.0.tar.gz` (atau salin folder ke `plugins/generic/`), aktifkan "Crossmark Button".
